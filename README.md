# mlb-playoff-corr

I want to build a model that figures out what is the most common correlation between a team and how far they make it in the playoffs. 
- Wildcard
- ALDS/NLDS
- ALCS/NLCS
- World Seires

Starting Point:

Start with since the expansion of the playoffs, then if there is not enough data then move backwards. Baseball evolution makes it so I want to keep the data as current as possible.
